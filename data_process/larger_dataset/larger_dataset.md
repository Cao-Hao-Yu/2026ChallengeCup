# Larger Dataset

### 数据预处理步骤

1. 对每个数据集，首先将其原始标注转换成txt标注格式

2. 统一每个数据集的层级映射，类别映射（子类-1表示无细粒度标注）

3. 将数据集转换为对应的obb（hbb）格式

4. 将模型输入调整至1280左右，并且数据集需要进行切片
   
5. 删除每个数据集中不需要的数据（如过曝图像，无船舶目标的街景，还有切片产生的空图像）

6. 划分train，val，test数据集，val包括所有数据集，test中只包括比赛数据集，并且与val中相同

7. 给出官方评分方式的算法，用模型给出的json做测试，其中obb模型需要使用其外接框计算
